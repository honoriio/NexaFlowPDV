## NexaFlowPDV

O **NexaFlowPDV** é um sistema de ponto de venda (PDV) desenvolvido com **Django** e **PostgreSQL**, projetado para oferecer uma base escalável, modular e de alta performance para gestão comercial.

O projeto segue uma arquitetura organizada por domínio, permitindo separação clara entre responsabilidades como clientes, produtos, vendas e fornecedores, facilitando manutenção e evolução contínua do sistema.

### 🚀 Tecnologias utilizadas

* Python + Django
* Django ORM
* PostgreSQL
* Django Admin (customizável)
* (Opcional futuro: Django REST Framework para API)

### 📦 Objetivo do projeto

Construir um sistema PDV moderno, com foco em:

* Escalabilidade e modularização
* Estrutura pronta para expansão (APIs, frontend separado, microserviços)
* Controle eficiente de vendas, clientes e estoque
* Base sólida para integrações futuras (BI, automações, sistemas externos)

### 🧠 Arquitetura

O sistema é dividido em apps Django independentes, como:

* customers (clientes)
* products (produtos)
* sales (vendas)
* suppliers (fornecedores)

Cada módulo possui suas próprias responsabilidades, seguindo boas práticas de separação de domínio.

### ⚙️ Status do projeto

Em desenvolvimento inicial, com estrutura base sendo construída e modelos sendo definidos.
